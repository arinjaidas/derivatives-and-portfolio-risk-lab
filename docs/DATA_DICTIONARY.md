# Data dictionary

| Field or concept | Definition | Unit or rule |
| --- | --- | --- |
| spot and strike | Positive prices in the same units | Required |
| maturity | Time to expiry in years | Nonnegative |
| rate and dividend_yield | Finite continuously compounded annual rates | Fractions |
| volatility | Annualised return volatility | Nonnegative fraction |
| kind | call or put | European exercise |

New reconstruction of the core valuation and payoff methods using illustrative inputs.

The default example is synthetic or illustrative. Real-data inputs require their own permissions, definitions and source audit. Missing or infinite values are not evidence of a valid measured zero.
